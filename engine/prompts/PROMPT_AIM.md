# PROMPT_AIM — alias de compatibilidade

No Docqui Caixa, o artefato se chama **AIMM — Análise de Impacto de Mudança para Manutenção**. O procedimento canônico é [`PROMPT_AIMM.md`](PROMPT_AIMM.md).

Ao receber este prompt antigo, leia e execute integralmente `engine/prompts/PROMPT_AIMM.md`. Gere `analise-impacto/AIMM-<CHAVE>.md`; preserve as chaves e os estados do ticket. Arquivos `AIM-*` existentes continuam sendo lidos, mas novas saídas usam `AIMM-*`.
